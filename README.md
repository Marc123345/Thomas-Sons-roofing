# Thomas & Sons Painting and Roof Coating

Website for Woodrow "Woody" Gorman's company, Indianapolis, IN. Built on the
BuildGo React template (~/Desktop/buildgo-react), ported to Next.js (pages
router), with ProGrade's patterns: before/after sliders, text-first mobile bar,
Jotform-ready estimate form with TCPA consent, one data file.

- All copy and business data: `data/site.js` (OPEN ITEMS at the bottom).
- Photos are the company's own, from Facebook. Originals → sizes with
  `npm run media -- <folder>` (scripts/build-media.mjs).
- `npm run dev` (port 5250), `npm run build` (writes sitemap + robots first).
